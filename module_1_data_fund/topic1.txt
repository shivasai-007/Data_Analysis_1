2.Structured vs. Unstructured Data

| Feature      | Structured Data                 | Unstructured Data                                     |
| ------------ | ------------------------------- | ----------------------------------------------------- |
| Organization | Organized into rows and columns | No fixed format                                       |
| Schema       | Predefined schema               | No predefined schema                                  |
| Storage      | SQL databases, Excel, CSV       | Files, cloud storage, NoSQL                           |
| Querying     | Easy using SQL                  | Requires specialized tools (NLP, Computer Vision, AI) |
| Analysis     | Simple and fast                 | More complex                                          |
| Examples     | Sales records, student data     | Images, videos, emails, PDFs                          |

1. Structured Data
    Def:Structured data is data that is organized in a fixed format, usually in rows and columns. Each column has a
    specific meaning, making it easy to store, search, and analyze.

2. Unstructured Data
    Def:Unstructured data is data that does not follow a predefined format or table structure.
    It often contains text, images, audio, video, or other rich content.

3.Metrics Explained
What is a Metric?
    A metric is a measurable value used to evaluate, monitor, and improve the performance of a 
    process, business, system, or individual.

    Simple Definition:A metric is a number that tells you how well something is performing.

| Metric              |   Value |
| ------------------- | ------: |
| Total Sales         | $25,000 |
| Orders              |     500 |
| Customers           |     420 |
| Average Order Value |     $50 |
| Return Rate         |      2% |

Why Are Metrics Important?

    Metrics help organizations:

    Measure performance
    Track progress over time
    Identify problems
    Make data-driven decisions
    Compare different products, teams, or time periods
    Set goals and monitor improvement
2. Data Analytics

Common metrics include:
    Average
    Sum
    Count
    Maximum
    Minimum
    Median
    Standard Deviation

what is KPIs?(Key Performance Indicator)

a specific metrics that directly Measure progress toward a goal 

Think of it this way:

Data → Raw facts
Metrics → Measurements calculated from data
KPIs → The most important metrics tied to business goals

| Metric              | KPI?              |
| ------------------- | ----------------- |
| Website Visitors    | ❌ Not necessarily |
| Revenue             | ✅ Yes             |
| Conversion Rate     | ✅ Yes             |
| Likes on Instagram  | ❌ Usually No      |
| Average Order Value | ✅ Yes             |

ex :

❌ Bad KPI:
Increase sales.

✅ Good KPI:
Increase monthly sales revenue by 15% within the next 6 months.

| Metric                               | KPI                                                 |
| ------------------------------------ | --------------------------------------------------- |
| Measures any aspect of performance   | Measures progress toward an important business goal |
| Many metrics exist                   | Only a few metrics become KPIs                      |
| General measurement                  | Strategic measurement                               |
| May or may not affect business goals | Directly tied to business objectives                |

Key Takeaways
KPIs are the most important metrics for measuring success against business goals.
Every KPI is a metric, but not every metric is a KPI.
KPIs should be SMART: Specific, Measurable, Achievable, Relevant, and Time-bound.
Data Analysts regularly calculate, monitor, and visualize KPIs using Excel, SQL, Python, Power BI, and Tableau.
In interviews, remember this simple distinction:
Data = Raw facts
Metric = Measurement
KPI = Measurement that directly tracks an important business objective
